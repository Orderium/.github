## About

Orderium is a plugin for [Paper](https://papermc.io) servers that adds a full order and delivery system to your server's economy. It is built to be tuned to your server rather than the other way around, with menus, messages, and storage that you configure yourself.

This organization is used for:
1. Taking the username/organization name "Orderium" on GitHub;
2. Hosting Orderium's documentation website;
3. Storing repositories related to Ordeirum.
